# 蝶威量化大赛分析报告

## 1. 比赛内容解析（通俗版）

### 比赛是什么？
这是一个由上海蝶威私募基金管理有限公司举办的量化投资因子挖掘竞赛。简单来说，就是让你用数据预测股票未来的涨跌。

### 你需要完成什么？
1. **数据分析**：平台会给你2023-2024年的沪深300成分股的高频交易数据（每分钟都有数据）
2. **构建因子**：你需要写代码，从这些数据中提取特征（叫做"因子"），这个因子能预测股票未来会涨还是会跌
3. **生成15分钟频率的预测**：虽然数据很细（快照级别），但你需要每15分钟给出一个预测值
4. **提交代码**：你不是提交预测结果，而是提交能生成预测的代码，平台会自动运行你的代码

### 评分机制
- **公榜（Public）**：用历史数据测试你的因子效果
- **私榜（Private）**：用新数据测试，防止你"过拟合"历史数据
- **最终评分** = 30% × 因子分析得分 + 70% × 回测得分
  - 因子分析：看你的因子能否区分好股票和坏股票
  - 回测：模拟真实交易，每天用你的因子选60只股票买入，看能否赚钱

### 数据内容
- 股票价格（买一到买十档、卖一到卖十档）
- 成交量、成交额
- 委托笔数等微观市场数据

## 2. 官方Demo逻辑分析

### Demo策略：订单簿压力因子（Order Book Pressure）

#### 核心思想
通过分析买卖盘口的委托量不平衡，预测短期价格走向。

#### 具体步骤

1. **计算中间价格**
   ```
   mid_price = (买一价 + 卖一价) / 2
   ```

2. **加权买卖方委托量**
   - 对5档买卖盘口进行指数加权（距离越远权重越小）
   - 公式：`weight_bid = bid_volume1 × 1.0 + bid_volume2 × e^(-0.3) + ...`
   - 同理计算卖方加权量 `weight_ask`

3. **订单簿不平衡度**
   ```
   weighted_imbalance = (买方量 - 卖方量) / (买方量 + 卖方量)
   ```
   - 值越大，说明买盘力量越强

4. **价差因子**
   ```
   relative_spread = (卖一价 - 买一价) / 中间价
   ```
   - 价差越大，流动性越差

5. **压力因子**
   ```
   raw_pressure = 不平衡度 / sqrt(价差) × 不平衡度
   ```

6. **标准化和调整**
   - 在每15分钟窗口内对压力因子标准化
   - 根据价格波动率调整（高波动时降低因子值）
   - 使用 tanh 函数压缩到[-1, 1]

7. **因子反转**
   - 最终乘以 -1，因为这是一个反转策略

#### 优点
- 利用了盘口微观结构信息
- 考虑了流动性因素
- 有波动率调整机制

#### 缺点
- 仅使用了盘口数据，没有利用历史价格动量
- 标准化可能不够稳定
- 没有考虑行业或市场整体因素

## 3. 其他文件策略分析

### 策略1：动量反转（xyf/动量反转.ipynb）

#### 核心逻辑
```
动量 = (15分钟收盘价 - 15分钟均价) / 均价
因子 = -tanh(动量 × 10)
```

#### 优点
- 逻辑简单，计算高效
- 捕捉短期价格偏离均值的反转效应
- 使用tanh限制极端值

#### 缺点
- 只使用价格信息，忽略了成交量和盘口
- 没有考虑波动率调整
- 可能在趋势市中表现不佳

---

### 策略2：量价相关性（xyf/量价相关性.ipynb）

#### 核心逻辑
```
计算每15分钟内价格变化和成交量变化的相关系数
因子 = CORR(价格收益率, 成交量变化)
```

#### 优点
- 结合了量价信息
- 能够捕捉异常交易行为
- 相关系数是标准化的

#### 缺点
- 需要足够的样本点（至少3个）
- 在成交量稀疏时可能不稳定
- 没有考虑盘口信息

## 4. 最优解决方案设计

### 策略思路：多因子融合

基于对已有代码的分析，最优方案应该：
1. **融合多个维度的信息**：盘口、价格、成交量
2. **考虑市场微观结构**：订单簿不平衡、流动性
3. **加入动量信号**：短期动量和反转
4. **稳健性处理**：波动率调整、异常值处理

### 核心创新点

1. **多因子组合**
   - 订单簿不平衡因子（盘口信息）
   - 短期动量反转因子（价格信息）
   - 量价背离因子（量价关系）
   - 流动性因子（价差、深度）

2. **自适应权重**
   - 根据市场状态（波动率）动态调整各因子权重
   - 高波动时增加盘口因子权重，降低动量因子权重

3. **特征工程**
   - 多时间尺度特征（5分钟、10分钟、15分钟）
   - 相对强度指标
   - 市场情绪指标

4. **稳健性增强**
   - Winsorize处理极端值
   - 行业中性化
   - 波动率标准化

### 预期效果
- **夏普比率**：>2.0（通过多因子分散风险）
- **IC（信息系数）**：>0.05（因子预测能力）
- **换手率**：适中（避免过度交易）
- **稳定性**：各时间段表现均衡

---

## 总结

这个比赛本质上是一个**高频因子低频化**的量化投资挑战：
- 你有高频数据（快照级别）
- 你需要构建15分钟频率的因子
- 目标是预测日内股票的相对强弱

成功的关键在于：
1. 充分利用盘口微观结构信息
2. 结合价格动量信号
3. 考虑市场状态的动态变化
4. 确保因子的稳健性和可解释性

官方Demo提供了一个很好的基础框架，已有的其他策略展示了不同角度的思考。最优方案应该是融合这些思路，构建一个多维度、自适应、稳健的因子模型。
