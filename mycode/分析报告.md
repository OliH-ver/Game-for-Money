## 2. 官方Demo的逻辑是怎么样的

### Demo策略：订单薄压力因子（Order Book Pressure Factor）

**核心思想**：
通过分析买卖盘口的委托量差异，判断市场短期买卖压力，预测价格的均值回归。

### 详细逻辑

#### 第一步：计算加权买卖压力
- 使用买卖盘口的**5档数据**（bid1-bid5, ask1-ask5）
- 对不同档位施加**指数衰减权重**：
  ```
  权重 = [1.0, e^(-0.3), e^(-0.6), e^(-0.9), e^(-1.2)]
  ```
- 离盘口越远，权重越小（因为远档信息可靠性低）

#### 第二步：计算买卖不平衡度（Imbalance）
```python
加权买量 = sum(bid_volume[i] × weight[i])
加权卖量 = sum(ask_volume[i] × weight[i])

Imbalance = (加权买量 - 加权卖量) / (加权买量 + 加权卖量)
```
- 结果范围：[-1, 1]
- 正值 = 买压大，负值 = 卖压大

#### 第三步：考虑价差（Spread）调整
```python
相对价差 = (ask1 - bid1) / mid_price

压力因子 = Imbalance / sqrt(|相对价差|)
```
- 价差小 → 流动性好 → 压力信号更可靠（分母小，因子值放大）
- 价差大 → 流动性差 → 压力信号打折扣

#### 第四步：波动率调整
- 计算15分钟窗口内的价格波动率
- 如果波动率超过80%分位数（高波动期）：
  ```python
  压力因子 = 压力因子 × 0.3  # 降低70%权重
  ```
- **原因**：高波动期噪音大，信号可靠性低

#### 第五步：标准化和映射
```python
# 横截面标准化（z-score）
z_score = (压力因子 - 平均值) / 标准差

# 用tanh函数映射到[-1, 1]
最终因子 = tanh(z_score)
```

### Demo的优缺点

**优点**：
1. ✅ 利用高频微观结构信息（盘口数据）
2. ✅ 多层次处理：权重、价差、波动率调整
3. ✅ 标准化后具有可比性
4. ✅ 适合短期均值回归策略

**缺点**：
1. ❌ 高度依赖数据质量（盘口数据缺失/错误会严重影响）
2. ❌ 只关注均值回归，在趋势市中表现不佳
3. ❌ 参数较多（权重、阈值），可能过拟合
4. ❌ 计算复杂度高

## 3. 其余文件的策略及优缺点分析

### 3.1 价格排序因子（价格排序.ipynb）

**策略**：横截面价格排名，低价股优先

**计算方法**：
```python
价格排名 = 按价格降序排列的排名
因子值 = 1 - (总数 - 排名) / (总数 - 1)
# 最低价 → 1.0，最高价 → 0.0
```

**优点**：
- ✅ 极简单，易实现
- ✅ 低价股效应在A股有一定历史规律
- ✅ 计算速度快

**缺点**：
- ❌ 完全忽略成交量、波动率等信息
- ❌ 容易被小市值垃圾股干扰
- ❌ 没有风险控制
- ❌ 单一维度，信息量不足

---

### 3.2 动量反转因子（动量反转.ipynb）

**策略**：日内均值回归，价格偏离窗口均值时反向操作

**计算方法**：
```python
原始动量 = (当前价 - 窗口均价) / 窗口均价
因子值 = -tanh(原始动量 × 10)
# 价格高于均值 → 负值（做空信号）
# 价格低于均值 → 正值（做多信号）
```

**优点**：
- ✅ 理论基础扎实（日内均值回归）
- ✅ tanh函数抑制极端值
- ✅ 适合震荡市

**缺点**：
- ❌ 趋势市中会持续亏损
- ❌ 窗口长度选择敏感
- ❌ 忽略成交量确认
- ❌ 可能在横盘市频繁交易

---

### 3.3 价格&反转复合因子（价格&反转复合.ipynb）

**策略**：结合低价效应 + 均值回归

**计算方法**：
```python
价格因子 = 1 - (N - 价格降序排名) / (N - 1)
反转因子 = -tanh((当前价 - 均价) / 均价 × 10) / 2 + 0.5
复合因子 = 0.2 × 价格因子 + 0.8 × 反转因子
```

**优点**：
- ✅ 双重逻辑，降低单一因子噪音
- ✅ 80%权重在动量，平衡合理
- ✅ 比单一因子稳健

**缺点**：
- ❌ 固定权重不适应市场变化
- ❌ 价格排序部分的缺陷仍存在
- ❌ 两个因子的相关性可能高，分散化不足

---

### 3.4 量价相关性因子（量价相关性.ipynb）

**策略**：计算价格变动与成交量变动的相关性

**计算方法**：
```python
价格序列 = 15分钟内的收益率序列
成交量序列 = 15分钟内的成交量变化序列
因子值 = Pearson相关系数(价格序列, 成交量序列)
# 正相关 → 趋势确认，负相关 → 背离信号
```

**优点**：
- ✅ 独特视角，量价配合
- ✅ 相关系数天然标准化[-1, 1]
- ✅ 捕捉资金流向一致性

**缺点**：
- ❌ 需要足够数据点（低流动性时不可靠）
- ❌ 成交量数据质量问题
- ❌ 相关性的经济学解释较弱
- ❌ 样本数不足时容易虚假相关

## 4. 最优解决方案设计

### 设计思路

基于以上分析，我设计了一个**多因子融合策略**，结合各策略的优点：

1. **多维度信号源**：盘口压力 + 动量反转 + 量价关系
2. **自适应权重**：根据市场状态动态调整
3. **风险控制**：波动率过滤 + 异常值处理
4. **工程优化**：代码清晰，易调试

### 核心因子组合

#### 因子1：改进订单薄压力（权重35%）
- 基于Demo，简化参数
- 仅使用3档数据（降低数据依赖）
- 动态波动率阈值

#### 因子2：量价协同因子（权重30%）
- 价格动量 × 成交量变化
- 捕捉资金流向
- 处理缺失值

#### 因子3：短期反转因子（权重25%）
- 5分钟/15分钟双周期
- 自适应阈值
- 避免过度交易

#### 因子4：市场微观结构因子（权重10%）
- 买卖价差变化
- 成交量不规则性
- 辅助信号

### 融合方法

```python
最终因子 = 横截面排名加权(
    0.35 × 订单薄压力排名 +
    0.30 × 量价协同排名 +
    0.25 × 反转因子排名 +
    0.10 × 微观结构排名
)
```

### 关键特性

1. **稳健性**：多因子分散，单一因子失效不崩溃
2. **适应性**：权重可根据回测调整
3. **可解释性**：每个因子都有经济学逻辑
4. **工程性**：模块化，易测试

### 预期优势

- 比单一因子更稳定（Sharpe Ratio提升）
- 在不同市场环境下表现均衡
- 对数据噪音的容忍度更高
- 16个时间截面测试下得分更平稳

本次比赛的核心挑战是：

- **量价关系**（资金流向）
