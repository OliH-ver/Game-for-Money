## 1️⃣ 这个比赛的内容是什么，我该完成什么来参加这个比赛？

### 🎯 比赛本质
这是一个**量化投资因子挖掘**比赛。用通俗的话说：

> **你需要写一段程序，通过分析股票的历史交易数据（价格、成交量、买卖盘口等），来预测未来哪些股票会涨。就像天气预报，但预报的是股票涨跌。**

### 📋 具体任务

1. **输入**：沪深300成分股的分钟级快照数据（2023-2024年）
   - 价格、成交量、成交额
   - 10档买卖盘口委托量和笔数

2. **输出**：一个Python函数，返回每只股票在每个15分钟时点的"因子值"
   - 因子值越高 = 预测涨得越好
   - 格式：`DataFrame(date, instrument, factor)`

3. **评估**：
   - 用你的因子模拟投资：每天选因子最高的60只股票，等权买入
   - 在16个不同时间点（09:45, 10:00...15:00）测试
   - 评分指标：超额收益、夏普比率

4. **比赛流程**：
   - **公榜**：历史数据回测排名
   - **私榜**：新数据动态测试（真实有效性）
   - **决赛**：研究报告 + 现场答辩

## 2️⃣ 官方Demo的逻辑是怎么样的？

### 📊 Demo策略：订单簿压力因子

**核心思想**：通过买卖盘口的委托量差异，判断短期买卖压力，预测价格均值回归。

### 🔄 计算流程

#### Step 1: 加权买卖量
```
使用5档盘口数据，指数衰减权重：
weight = [1.0, e^(-0.3), e^(-0.6), e^(-0.9), e^(-1.2)]

加权买量 = bid_volume1 × 1.0 + bid_volume2 × 0.74 + ...
加权卖量 = ask_volume1 × 1.0 + ask_volume2 × 0.74 + ...
```

#### Step 2: 不平衡度
```
Imbalance = (加权买量 - 加权卖量) / (加权买量 + 加权卖量)
范围：[-1, 1]
正值 = 买压大，负值 = 卖压大
```

#### Step 3: 价差调整
```
相对价差 = (ask1 - bid1) / mid_price
压力因子 = Imbalance / sqrt(|相对价差|)

逻辑：价差小（流动性好）→ 压力信号更可靠
```

#### Step 4: 波动率过滤
```
如果波动率 > 80%分位数（高波动期）：
    压力因子 = 压力因子 × 0.3  （降低70%）
    
原因：高波动期噪音大，信号不可靠
```

#### Step 5: 标准化
```
z_score = (压力因子 - 均值) / 标准差
最终因子 = tanh(z_score)  // 映射到[-1, 1]
```

### ✅ Demo优点
- 利用高频微观结构信息（盘口数据）
- 多层次处理（权重、价差、波动率调整）
- 适合短期均值回归策略

### ❌ Demo缺点
- 高度依赖数据质量（缺失/错误影响大）
- 只关注均值回归，趋势市表现差
- 参数多，可能过拟合
- 计算复杂度高

## 4️⃣ 最优解决方案

### 🎨 设计理念

基于对现有代码的分析，我设计了一个**多因子融合策略**，综合各策略优点：

```
最优方案 = 订单簿压力 + 量价协同 + 短期反转 + 微观结构
         (简化版)    (新增)      (改进版)    (新增)
```

### 🏗️ 架构设计

#### 4个子因子

| 因子 | 权重 | 核心思想 | 改进点 |
|------|------|---------|--------|
| **订单簿压力** | 35% | 3档加权买卖不平衡<br>价差归一化<br>波动率调整 | • 简化为3档（降低数据依赖）<br>• 动态波动率阈值 |
| **量价协同** | 30% | 价格动量 × 量价一致性 | • 新增：捕捉资金流向<br>• 处理缺失值 |
| **短期反转** | 25% | 价格偏离均值 → 反向 | • tanh非线性映射<br>• 自适应阈值 |
| **微观结构** | 10% | 价差变化 + 成交量不规则性 | • 新增：辅助信号<br>• 流动性质量 |

#### 融合机制

```python
# 1. 横截面排名（百分位）
rank1 = percent_rank(订单簿压力)  # [0, 1]
rank2 = percent_rank(量价协同)
rank3 = percent_rank(短期反转)
rank4 = percent_rank(微观结构)

# 2. 加权融合
composite = 0.35*rank1 + 0.30*rank2 + 0.25*rank3 + 0.10*rank4

# 3. 横截面标准化
z_score = (composite - mean) / std

# 4. tanh映射
final_factor = tanh(z_score)  # [-1, 1]
```

### 🌟 核心优势

#### 1. 稳健性 (Robustness)
- **多因子分散**：单一因子失效不崩溃
- **排名加权**：对异常值更稳健
- **横截面标准化**：消除时期差异

#### 2. 适应性 (Adaptiveness)
- **波动率感知**：高波动自动降低敏感度（60%衰减）
- **动态阈值**：75%分位数自适应
- **市场中性**：适应震荡/趋势/高低波动各种环境

#### 3. 可解释性 (Interpretability)
- 每个子因子有明确经济学逻辑
- 权重分配合理：
  - 微观结构最重要（订单簿）
  - 资金确认次之（量价）
  - 统计规律辅助（反转）
  - 市场质量补充（微观结构）

#### 4. 工程性 (Engineering)
- **模块化**：每个因子独立，易调试
- **SQL实现**：充分利用DAI引擎性能
- **注释完整**：易理解和修改
