## 🎯 策略核心

### 多因子自适应融合策略

本策略融合了4个维度的市场信息：

#### 1️⃣ 订单簿不平衡因子 (Order Book Pressure)
- **权重**: 30-45%（根据波动率自适应）
- **逻辑**: 分析买卖盘口的5档委托量，使用指数衰减加权计算买卖力量对比
- **公式**: `imbalance = (weighted_bid - weighted_ask) / (weighted_bid + weighted_ask)`
- **优势**: 捕捉短期资金流向，对价格动向敏感

#### 2️⃣ 短期动量反转因子 (Mean Reversion)
- **权重**: 20-30%
- **逻辑**: 计算15分钟收盘价偏离窗口均价的程度，利用均值回归效应
- **公式**: `momentum = -(close_price - avg_price) / avg_price`
- **优势**: 捕捉日内超涨超跌，反转交易

#### 3️⃣ 量价背离因子 (Volume-Price Divergence)
- **权重**: 25%
- **逻辑**: 计算价格收益率与成交量变化率的相关系数，识别异常交易
- **公式**: `divergence = -CORR(returns, volume_change_rate)`
- **优势**: 发现价涨量缩、价跌量增等异常情况

#### 4️⃣ 流动性因子 (Liquidity)
- **权重**: 10-15%
- **逻辑**: 综合价差和盘口深度，衡量交易成本
- **公式**: `liquidity = -spread / LOG(depth)`
- **优势**: 避免流动性陷阱，控制交易成本

### 🔄 自适应机制

根据市场波动率动态调整权重：

| 市场状态 | 订单簿 | 动量 | 量价 | 流动性 |
|---------|-------|------|------|--------|
| 高波动  | 45%   | 20%  | 25%  | 10%    |
| 低波动  | 30%   | 30%  | 25%  | 15%    |

**设计原理**：
- 高波动时，价格剧烈波动，订单簿信息更可靠，动量容易失效
- 低波动时，价格稳定，动量反转更有效

### 🛡️ 稳健性处理

1. **标准化**: 窗口内z-score标准化，消除量纲影响
2. **极端值处理**: tanh函数压缩到[-1, 1]，防止异常值
3. **缺失值处理**: COALESCE确保计算稳定
4. **最小样本**: 相关性计算需>=3个样本点

## 💡 优化建议

### 可调整参数

1. **指数衰减权重** (line ~130-140)
   ```sql
   EXP(-0.3), EXP(-0.6), EXP(-0.9), EXP(-1.2)
   ```
   - 当前：距离越远权重越小
   - 可调整：改变衰减速度

2. **自适应权重** (line ~280-295)
   ```sql
   CASE WHEN volatility > threshold THEN 0.45 ELSE 0.30 END
   ```
   - 当前：高低波动两档
   - 可优化：增加中等波动档位

3. **tanh放大系数** (line ~315)
   ```sql
   TANH(raw_factor * 3.0)
   ```
   - 当前：3倍放大
   - 可调整：1-5之间

### 进阶优化方向

1. **行业中性化**: 对因子进行行业去均值
2. **时段差异化**: 不同时段使用不同权重
3. **动态阈值**: 波动率阈值自适应调整
4. **多时间尺度**: 加入5分钟、10分钟特征
